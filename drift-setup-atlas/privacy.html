파일 처리와 저장

선택한 INI·LUT·RTO·ZIP과 복원 JSON은 이 브라우저 안에서 읽습니다. 앱에는 분석 파일을 서버에 업로드하거나 외부 API에 보내는 기능이 없습니다. 자동 저장은 브라우저 localStorage를 사용하며 사용자 계정 기반 저장소가 아닙니다.

같은 브라우저·같은 사이트에 저장됩니다. 기기 변경, 저장소 삭제, 시크릿 모드 종료 등에 대비해 JSON 백업을 따로 보관하세요. 암호화된 금고나 로그인 기반 접근 통제는 제공하지 않습니다.

기존 로컬 V2에서 이동

기존 HTML을 열고 상단 JSON 백업을 저장한 뒤, 웹판 상단 복원에서 해당 JSON을 선택합니다. 복원은 현재 웹판 기록을 대체하므로 웹판에도 기록이 있다면 먼저 백업하세요. 제공된 개인용 이동 파일은 본인 브라우저에서만 복원하고 GitHub에는 올리지 마세요.

외부 연결

사이트 파일을 받기 위해 호스팅 서버와 통신합니다. 참고자료 링크를 직접 누르면 해당 외부 사이트로 이동합니다. 앱 자체에 추적·광고·분석 SDK는 없습니다. 호스팅 제공자의 접속 로그 처리는 해당 제공자 정책을 따릅니다.

지원 범위

이 앱은 시뮬레이터 연구용 규칙 기반 시험 도구입니다. 실차의 안전성이나 특정 세팅의 성능을 보증하지 않습니다. 자동 클라우드·Notion 동기화, 실시간 게임 연결은 없습니다.
