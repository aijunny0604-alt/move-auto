롤 홀드 → 킥·액셀 → 빠른 회두 → 캐치 → 추진 · 후륜구동 Assetto Corsa 연구용 조건부 판단 지도

01 차량 확인같은 차·버전 / 원본 A 보존
→
02 조건 확인속도·기어·타이어·보조 통일
→
03 원인 분류입력·락·접촉부터 분리
→
04 B 후보 생성허용 STEP으로 한 설정군만
→
05 주행 비교A/B 반복 → 재검증 → 사용자 채택

01 / 홀드

준비·홀드에서 앞이 바깥으로 밀린다

→ 앞 ARB −1단계

킥을 넣기 전에 뒤가 먼저 풀린다

→ 뒤 ARB −1단계

흔들림은 없는데 홀드 롤각이 너무 크다

→ 정상 롤 강성·기하 확인 / 숫자 보류

02 / 킥·첫 회두

킥 직후 너무 많이 돌아간다

→ 뒤 ARB −1단계

홀드는 좋은데 킥 후 회두가 둔하다

→ 뒤 ARB +1단계

킥 후 RPM이 꺼지며 힘이 비어버린다

→ 재결합 RPM·기어 확인 / 숫자 보류

03 / 좌우 전환

앞 차체가 여러 번 출렁인 뒤 정착한다

→ 앞 Rebound +1단계

뒤 차체가 여러 번 출렁인 뒤 정착한다

→ 뒤 Rebound +1단계

앞이 펴지는 움직임이 억눌려 느리다

→ 앞 Rebound −1단계

04 / 캐치

목표 각도까지는 좋은데 캐치가 늦다

→ 입력·셀프스티어 확인 / 숫자 보류

05 / 탈출·재가속

받았는데 액셀에서 한 번 더 말린다

→ 토크·스로틀 시점 확인 / 숫자 보류

각도는 좋은데 앞으로 못 나간다

→ 뒤 ARB −1단계 검토

06 / 조건·요철

요철을 밟을 때만 뒤가 튄다

→ 스트로크·Fast 감쇠 확인 / 숫자 보류

바닥·범프스톱 또는 앞 락이 의심된다

→ 락·접촉 해소 먼저 / 추천 중지

좌우 전환의 성격이 다르다

→ 비대칭 원인 확인 / 추천 중지
보류조건·기록이 부족하다.
빈칸을 0으로 바꾸지 않는다.
원복 우선B에서 스핀 또는 보호 항목 악화.
다음 숫자 대신 원인부터 재검토.
차이 불명확사전 최소 개선폭에 미달.
더 좋은 세팅이라고 단정하지 않는다.
재검증 후보주목표 개선 + 보호 조건 통과.
A로 재확인한 뒤 B 채택을 결정.

전제: 표의 방향은 원인 후보를 분리하는 시험이다. 타이어·간섭·입력 문제가 없고 해당 차 setup.ini 해석이 가능할 때만 적용한다. 비대칭·미확인 LUT·구동방식 불일치는 자동 변경하지 않는다. 댐퍼·스프링은 대칭 축의 좌우를 한 설정군으로 취급한다.

보호: 홀드·캐치·추진감·출구 속도. 한 변수 비교는 상호작용이나 전역 최적값을 보장하지 않는다. 일반 원리: OptimumG / Penske / Stanford. 상세 출처·원리는 동봉 21쪽 가이드북과 앱에 수록.
