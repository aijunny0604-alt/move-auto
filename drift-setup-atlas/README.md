# DRIFT SETUP ATLAS — Web Edition

Assetto Corsa 후륜구동 드리프트 세팅 연구 도구입니다. 롤 홀드 → 킥/액셀 → 회두 → 캐치 → 추진을 구분하며, 차량 파일과 주행 피드백에서 한 항목 A/B 시험 및 채택·원복 판단으로 연결합니다.

## 게시 위치

이 디렉터리는 기존 무브 오토모티브 홈페이지와 독립적입니다. 기존 루트 홈페이지, 갤러리, 관리자 파일을 변경하지 않습니다.

GitHub Pages 게시 후 주소: https://aijunny0604-alt.github.io/move-auto/drift-setup-atlas/

## 개인정보 및 차량 자료

공개 앱에는 원본 차량 모드 데이터·개인 주행 기록·개인용 복원 파일을 포함하지 않습니다. 가져온 INI/LUT/RTO/ZIP과 시험 기록은 방문자 브라우저에서 처리·보관합니다. 기존 오프라인 ATLAS V2의 JSON 백업을 복원할 수 있습니다. 브라우저 저장소에 의존하므로 JSON 백업을 보관하세요. 기기 간 자동 동기화는 없습니다.

## 주요 기능

- 차량별 프로젝트 및 기준/작업값 분리
- 15개 증상 판단 지도와 조건부 시험 제안
- 같은 차량의 setup.ini 범위·STEP 확인, 미확인 값의 자동 조정 보류
- 원본을 보존하는 A/B 시험과 게임용 INI 다운로드
- 주행 결과 기록, 보류·원복·재검증 후보·사용자 채택
- 세팅 가이드북 및 JSON 백업·복원

규칙 기반 시험 지원 도구이며, 최적 세팅 자동 계산기나 실제 자동차의 안전성 인증 프로그램이 아닙니다. 엔진 출력·타이어 그립·스핀 위험을 정량 보증하지 않습니다.
