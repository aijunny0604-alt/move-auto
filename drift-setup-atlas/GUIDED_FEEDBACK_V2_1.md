# ATLAS 2.1 — 질문형 피드백 마인드맵

기존 피드백 폼을 질문에 답하며 가지를 따라가는 인터뷰로 변경했습니다. `/drift-setup-atlas/#feedback`에서 시작합니다.

## 흐름

문제의 순간 → 해당 장면의 증상 → 원인 구분 질문 → 강도·급격함·발생 빈도 → 유지할 좋은 느낌 → 비교 조건 → 주행 메모 → 다음 시험.

- 기존 15개 증상 규칙과 차량별 한 단계 제안을 재사용합니다. 분석 엔진과 차량·주행 데이터 저장 스키마는 변경하지 않았습니다.
- 예·아니오·모르겠어, 복수 선택, 설명이 붙은 0~10 슬라이더, 10회 기준 빈도, 실제 스핀 여부를 기록합니다.
- 선택 경로는 연결선으로 표시합니다. 이전 노드를 클릭해 수정할 수 있고 답변 변경 시 이후 확인을 초기화합니다.
- 증상 강도가 높아도 숫자 변경 폭을 자동 증폭하지 않습니다. 입력 비교·파일·조건이 미확인이면 수치를 보류합니다.
- 좋은 홀드·캐치·추진은 기존 A/B 평가와 함께 확인합니다. 앞의 방향 반응은 라인 오차·메모로 추가 관찰합니다.
- 자유 메모는 보관용입니다. API 호출이나 AI 자연어 해석은 하지 않습니다.
- 답변과 초안은 프로젝트의 `interview`에 저장되고 완료 인터뷰는 A/B 피드백 스냅샷에도 포함됩니다. 기존 JSON 백업/복원을 사용합니다.
- 새 진단 시 이전 답변은 최대 20개까지 `interviewHistory`에 보존됩니다. 현재 세팅이나 주행 기록은 지우지 않습니다.
- 인터뷰 이후 작업 A 또는 차량 자료가 바뀌면 기존 답변으로 자동 수치를 추천하지 않습니다.
- 모바일에서는 질문을 먼저 보여주며 지도를 펼쳐볼 수 있습니다.

## 검증

25개 질문 분기/검증 단위 검사, 30개 브라우저 UI·통합 검사를 통과했습니다. 브라우저는 제공된 소스를 오프라인 DOM에 직접 로드했고 저장소는 테스트용 fixture를 사용했습니다. 이 환경의 URL 탐색 제한 때문에 실제 공개 origin에서의 브라우저 동작·저장소 지속성은 직접 검증하지 못했습니다. 실제 게임의 성능 향상을 검증한 것이 아닙니다.

검사 범위: 15증상 접근, 입력 비교 분기, 미확인 조건 차단, 강도 0/10/미확인 처리, 이전 답변 변경, 작업 A 변경 감지, 기존 JSON 스키마 호환, A 원본 보존·B 한 단계 변경·INI 다운로드, 모바일 레이아웃과 키보드 슬라이더, 메모 HTML 이스케이프.

개인 차량 원본, 주행 로그, 실제 사용자 백업은 이 변경에 포함되지 않습니다. 변경은 `drift-setup-atlas/` 안에서만 이루어집니다.
